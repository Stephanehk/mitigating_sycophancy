# Curated minimal deps for the DPO+LoRA stakeholder-veto training run on Marlowe.
#
# This replaces a full `pip freeze` dump that had swept in unrelated research
# packages (figures_2/EconEvalsONET, dfa, ...) whose pins conflicted with each
# other (e.g. dfa wanted attrs<21 vs the frozen attrs==26) and prompted for
# GitHub auth. Here we pin only the packages the training pipeline actually
# imports, at the exact versions from the working local `llm` env, and let pip
# resolve the transitive deps — which is conflict-free.
#
# Versions verified together in /next/u/stephhk/miniconda3/envs/llm. torch 2.11
# + vllm 0.20.2 support Hopper (H100/sm_90).
#
# If vllm fails to build because torch isn't present yet, install torch first:
#   pip install torch==2.11.0
#   pip install -r marlowe_requirements.txt
# If the default torch/vllm wheels don't match Marlowe's CUDA, add the CUDA-12
# index, e.g.:  pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/cu124
